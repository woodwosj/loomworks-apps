How it works

  1. Create a retainer plan with included hours, rates, cycle start day, and rollover policy.
  2. Log consumption from timesheets or manually against the plan.
  3. The daily cron closes each cycle, computes rollover and overage hours, and drafts the renewal invoice.
  4. Your client reviews their hours log on the portal.
