Authorize.Net Address Truncate

Stop Authorize.Net payments from failing on over-long billTo addresses — clamp address, city and zip to the gateway schema limits.

Odoo 19.0 v19.0.1.0.0

Fixes Silent Payment Failures

Authorize.Net hard-rejects billTo blocks over its XML schema limits (address 60, city 40, zip 20 chars) before the card is ever attempted — this module removes that failure mode.

Clamps at the Right Hook

Overrides _get_specific_create_values() so clamping survives core’s partner-derived value population, instead of being silently overwritten.

Minimal Intervention

Only values over the limit are hard-sliced and right-stripped; in-range values are left completely untouched.

Provider-Scoped

Applies only to the authorize provider — other providers keep standard behavior.

Screenshots

How it works

  1. Install the module — it activates automatically for the Authorize.Net provider.
  2. When a transaction is created, any partner address, city, or zip over the gateway limit is sliced to the limit and right-stripped.
  3. In-range values pass through unchanged.
  4. Customers no longer hit unexplained payment failures from long addresses.
